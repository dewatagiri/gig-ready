# Rancang Rezeki

Mobile-first, single-file web app (`index.html`) for Malaysian gig workers (Grab, foodpanda, Lalamove, Shopee, freelancers).
Helps them see their real average income and lean month, set money aside, check loan readiness and prepare documents for financing.

**Planning aid only. Not financial advice, not a bank document, not proof of income.**

- Open `index.html` in a browser (works offline). BM/EN toggle, default BM.
- Data stays on the device (`localStorage`). No backend, no network calls, no bank logins.
- Set-aside percentages and the 65% debt limit are constants at the top of the script (placeholder, to be validated).
- See `SELF-TEST.md` for the 3-user (low, medium, high income) test results.
